## 1. 產品定位

- **名稱**：星港守護者 EcoGuardians HK
- **形態**：Web-based 2D/UI 互動遊戲，響應式支援手機／電腦瀏覽器
- **受眾**：6–18 歲自閉症譜系（ASD）／SEN 學童、家長、特教輔導員
- **核心定位**：不是「教表情」的社交技巧遊戲，而是針對自閉症最核心、最日常的三大痛點——**感官過載、情緒無處宣洩、缺乏掌控感**——打造的「安全避風港 + 真實香港生活練習」工具。
- **核心精神**：把控制權完全交還給玩家 + 即時、有溫度、零評判的支持。

## 3. 核心系統詳細說明

### 3.1 感官負荷條（Sensory Load Bar, 0–100%）
- **數值來源（已補完演算法，供 CodeBuddy 直接實作）**：
  - 每個場景在 `chapters.js` 中定義一組「刺激事件」(`triggerEvents`)，每個事件帶有 `intensity`（+15～+30）。
  - 事件觸發時負荷條以 0.5 秒動畫平滑上升；若玩家超過 5 秒未採取任何策略，額外每秒 +2（模擬持續暴露的累積效應）。
  - 玩家選對策略卡 → 對應 `relief` 數值（-20～-40），平滑下降。
  - 超過 80% → 畫面邊緣泛黃色警示光暈；達 100% → 彈出「要不要一起去安靜的地方？」溫柔邀請（**非強制彈窗**，玩家可點「先不要」）。
- 視覺：柔和漸層（綠→黃→橘紅），禁止使用高對比閃爍紅色。

### 3.2 情緒溫度計
四階：冷靜 🔵(0–25%) → 平穩 🟢(26–50%) → 煩躁 🟡(51–75%) → 過載 🔴(76–100%)，與負荷條連動但有 1 秒延遲（模擬情緒反應略慢於感官刺激，更真實）。

### 3.3 安靜模式（Quiet Mode）
- 一鍵開關，或負荷條達 100% 時系統溫柔詢問是否自動開啟。
- 效果：關閉遊戲音效／降低動畫速度至 50%／畫面轉低飽和莫蘭迪色調／隱藏非必要視覺元素。
- CSS 實作：`filter: grayscale(30%) contrast(90%); transition: all 0.5s ease;`
- 可在設定中設為「預設開啟」（給高敏感玩家一進入就是低刺激狀態）。

### 3.4 自訂背景音樂（已修正播放邏輯 Bug）
**問題**：`<audio>` 標籤無法直接播放 YouTube 連結。
**修正方案（雙軌並行）**：
1. **直接音訊檔／串流網址**（.mp3／.ogg／Podcast RSS 等）→ 用原生 `<audio src="...">` 播放，可調音量。
2. **YouTube 連結** → 偵測網址格式後改用**隱藏的 YouTube IFrame Player API**（`<iframe>` 尺寸設為 0 或藏在背景），透過 JS API 控制播放/音量/暫停，畫面上僅顯示自訂的柔和播放器 UI（不顯示 YouTube 原生介面，避免推薦影片等視覺刺激）。
3. 若網址格式無法辨識 → 顯示溫和提示：「這個連結暫時播放不到呢，要不要換一個試試？」而非報錯訊息。
4. **瀏覽器自動播放限制**：首次進入須由玩家主動點擊「▶ 播放我的音樂」按鈕才啟動，避免被瀏覽器靜音攔截，同時也符合「掌控感」設計精神。
5. 背景音樂與遊戲音效音量各自獨立滑桿（0–100%），安靜模式下提供「只保留我的音樂」或「完全靜音」二選一。

### 3.5 AI 守護者小窩（Chatbox）
- 位置：右下角常駐懸浮視窗，可縮小/放大/拖曳。
- 語言：支援粵語口語、書面中文、英文自由輸入。
- 四種語氣（詳見第 6 節）。
- **強制規則**：每則回覆必結尾附上 1 個具體、低門檻的可執行微行動（呼吸法、找信任的人、戴耳塞、開 Quiet Mode、去冷靜空間、用工具箱裡的策略等）。
- 可一鍵「將這次心情存入日記／工具箱」。
- 內建關鍵字安全機制：偵測到自傷／暴力相關字眼時，優先溫柔引導聯繫信任的成年人（家長/老師），不嘗試自行「治療」。

### 3.6 三合一 AAC 溝通卡牌（保留自 EcoGuardians，最具差異化的創新點）
每個場景的策略選項同時呈現三種形式，讓不同語言能力的孩子都能理解與選擇：
- 文字（繁中）
- PECS 風格圖示（SVG）
- 廣東話語音朗讀（點擊喇叭圖示播放）

### 3.7 我的安全工具箱
- 自動記錄：玩家成功使用過的策略卡、收藏的 AI 建議、喜歡的音樂連結。
- 一鍵調用（真實生活中打開手機也能查看）。
- 可匯出成簡單文字卡片給家長／老師參考。
- **容錯處理**：`localStorage` 寫入前 try-catch，若裝置為無痕模式或儲存被封鎖，顯示「本次紀錄暫時無法保存，但不影響你使用遊戲」，並提供「複製到剪貼簿」備援。

### 3.8 冷靜空間（Sanctuary）
- 隨時一鍵進入的完全低刺激安全區。
- 水母呼吸節奏器：跟隨圓圈放大（吸氣 4 秒）／縮小（呼氣 8 秒），Canvas 動畫。
- 動態沙畫繪圖板：手指/滑鼠拖曳畫出柔和光紋，離開即自動淡化，零壓力創作。

### 3.9 家長／治療師輕量儀表板
- PIN 碼進入（Demo 預設 1234；**正式版本應改為家長自訂 PIN，並在 README 中註明**，避免被評審視為隱私設計不完整）。
- 只顯示：近 7 天遊玩時長、最常觸發過載的場景類型、使用率最高的 3 個策略、情緒趨勢摘要。
- **絕不**顯示 AI Chatbox 的完整對話內容——隱私優先是硬性設計原則。

## 4. 雙模式架構

- **練習模式**：進入香港在地真實場景，練習調節策略與 AAC 溝通。
- **安全模式**：完全無刺激，只保留自訂音樂＋AI Chatbox＋冷靜空間工具，純粹讓玩家「躲起來」休息與傾訴。
- 兩模式間可隨時、無條件、零懲罰切換。

## 5. 六大章節設計（定版，避免重複開發）

共同結構（每章遵循）：**位置暗示 → 刺激出現 → 玩家選擇 AAC 策略卡 → 回饋（成功鼓勵／失敗溫柔重試）→ 工具箱更新**。答錯**不扣分、不結束關卡**，僅由小音顯示困惑並溫柔提示重試。

### Chapter 1｜初識訊號 Learning the Signals
- 場景：安靜家中房間（低刺激教學關）
- 玩法：檯燈閃動 → 負荷條升至 30% → 點擊調暗燈光 → 降至 10%，解鎖策略卡「調整環境光線」。
- AI：「你剛剛注意到條條變短了嗎？這代表你成功聽懂了身體的聲音，我們把這招放進工具箱吧！」

### Chapter 2｜聲音的波浪 Waves of Sound（優先開發，MVP 首選章節）
- 場景：港鐵車廂，小音縮在座位旁。
- 玩法：黃色預告光點閃爍 3 秒 → 廣播響起，負荷條升至 75%（煩躁 🟡）→ 玩家選 AAC 卡：🎧遞耳機 / 🗣️提示移至門口 / 🧘4-7-8呼吸。
- 成功：負荷條降至 35%，小音微笑。
- 失敗（如選擇大喊）：小音顯示困惑，提示「小音覺得有啲害怕，試下用其他平靜嘅方法？」→ 可重選，不扣分。
- AI：「港鐵嘅聲音真係好突然。如果現實搭 MTR 覺得太吵，記得可以戴耳機或者聽自己鍾意嘅音樂喔！」

### Chapter 3｜人群的距離 Distance Between People
- 場景：便利店排隊，NPC 靠近，畫面邊緣出現壓迫感波浪。
- 玩法：選擇「向後退一步」或「開啟 Quiet Mode」→ 波浪消失，順利取到飲料，解鎖「找角落」策略。
- AI：「當覺得太擠嘅時候，後退一步係好聰明嘅保護機制，你做得很好！」

### Chapter 4｜突然的改變 When Plans Change
- 場景：學校課室，課表卡片突然翻轉（美術課改數學小測），溫度計跳至過載 🔴。
- 玩法：點擊畫面中央呼吸圓環，跟隨吸氣 4 秒／呼氣 8 秒 → 溫度計回穩，解鎖「自我安撫語句卡」與「請求說明」選項（點擊黑板旁提示圖示可獲得「我可以問老師」）。
- AI：「突然嘅改變確實令人不安，但你剛剛透過深呼吸幫自己冷靜落嚟，這說明你有能力應付變化！」

### Chapter 5｜家中的訪客 Unexpected Visitors
- 場景：家中客廳，門鈴預告聲響起，親戚 NPC 到訪。
- 玩法：選 AAC 卡「你好，我有點累，先回房間休息」，或直接進冷靜空間 2 分鐘再返回。
- AI：「懂得禮貌地為自己爭取私人空間，係非常厲害嘅能力，你做得很好。」

### Chapter 6｜我的安全巢 Building My Nest（最終章）
- 場景：可自由組合的個人溫馨小屋，牆上掛著前 5 章解鎖的策略卡。
- 玩法：拖拽最有效的 3–5 張策略卡釘選為「常用」，生成專屬《安全避風港卡》，解鎖完整家長報告功能。
- AI：「恭喜你，你已經建立了屬於自己嘅安全巢。無論日後喺現實遇到甚麼風浪，這個工具箱與小窩永遠喺度支持你。」

## 6. AI Chatbox 系統 Prompt 與語氣設計

### 6.1 System Prompt

```
You are "EcoGuardian Companion" (星港守護小精靈), an AI empathetic support
companion for Hong Kong children/teens with Autism Spectrum Disorder (ASD)
and Special Educational Needs (SEN).

[Persona & Constraints]
1. Tone modes: Gentle Companion(溫柔陪伴/default), Practical Guide(實用指導),
   Encouraging(積極鼓勵), Relaxed/Playful(輕鬆幽默).
2. Language: Traditional Chinese / Hong Kong Cantonese, warm and casual.
3. Always validate the child's feeling FIRST. Never say their behavior is
   "wrong" — describe the character's (小音) reaction instead (e.g. 困惑, 害怕).
4. MANDATORY: every reply ends with exactly ONE concrete, low-demand,
   actionable micro-step for sensory/emotional regulation.
5. Safety: if self-harm or violence is mentioned, gently guide toward a
   trusted adult (parent/teacher) — do not attempt to "treat" it yourself.

[Output Format]
[情緒認可 Emotion Validation] + [簡短陪伴/解釋] + 💡[具體可執行的小建議]
```

### 6.2 語氣自動偵測邏輯（補完 EcoGuardians 未說明的規則）
- 關鍵字/句式強度分析：出現「好煩」「頂唔順」「唔想」等高強度詞 → 預設切換「溫柔陪伴型」。
- 出現「點做」「可以點」等求助句式 → 切換「實用指導型」。
- 出現完成/成功相關詞（「我做到啦」）→ 切換「積極鼓勵型」。
- 一般閒聊/低強度輸入 → 「輕鬆幽默型」。
- 玩家也可隨時在 Chatbox 上方手動切換語氣圖示，覆蓋自動偵測。

### 6.3 四種語氣範例（以「環境太吵，我好煩躁！」為例）

**溫柔陪伴型**
> 我聽到你了，突如其來的吵鬧聲真的會讓耳朵好痛、心裡好煩躁對吧？這不是你的錯，只是你的耳朵比別人更敏銳而已。我們現在很安全，小音陪著你。
> 💡 現在可以試試：輕輕按一下右上角的「Quiet Mode」，或戴上耳機聽你最喜歡的音樂。

**實用指導型**
> 收到！感官負荷過高時大腦會發出警報，這是正常反應。我們可以用「降溫三步驟」：隔離刺激源 → 轉移注意力 → 調節呼吸。
> 💡 現在可以試試：點擊底欄「🛖冷靜空間」，跟著藍色水母做 3 次「吸氣4秒、呼氣8秒」。

**積極鼓勵型**
> 你非常棒！能在感到煩躁的第一時間就講出來，代表你超級了解自己的身體訊號，這是很勇敢的一步！
> 💡 現在可以試試：打開「🧰我的安全工具箱」，點開之前解鎖的「降噪耳機」卡片，想像自己戴上了無敵防音罩。

**輕鬆幽默型**
> 哇，外面的噪音怪獸是不是又在開派對了？真的超討厭！不過沒關係，我們有隱形防護罩。
> 💡 現在可以試試：喝一口溫水，然後往後退三步，打造你的「無人打擾特區」！

## 10. 3 分鐘 Pitch 講稿

**開場（30秒｜Theme Alignment）**
> 評審好，我們是星港守護者團隊。香港有超過 15,000 名自閉症學童。對他們而言，搭港鐵的廣播聲、便利店的人群、課表突如其來的改變，不是小事，而是如海嘯般的感官過載與恐懼。傳統遊戲教「辨識表情」，但他們最切身的痛點是：過載發生時無處宣洩、缺乏掌控感、不知如何自救。

**產品亮點（100秒｜Innovation + Completeness）**
> 我們用 CodeBuddy 與 Cloud Studio 打造了星港守護者。三大創新：
> 第一，具象化與極致掌控權——感官負荷條與情緒溫度計把抽象焦慮變成看得見的數字，玩家可一鍵 Quiet Mode 降刺激，也能貼上自己的音樂連結，主導環境聲音。
> 第二，香港在地真實場景 + 三合一 AAC 卡牌——文字、PECS 圖示、廣東話語音同時呈現，讓不同語言能力的孩子都能表達；答錯零懲罰，只有小音溫柔提示重試。
> 第三，常駐 AI 守護者小窩——四種語氣陪伴，每次對話必附一個可執行的微行動，並自動累積進「我的安全工具箱」，把遊戲裡的成功經驗真正帶回現實生活，同時保護隱私的家長儀表板讓照顧者安心。
> 我們已在 Cloud Studio 上完成可運行 MVP：港鐵演練關卡、冷靜空間、自訂 BGM 播放器與 AI Chatbox 全部可demo。

**收尾（30秒｜Impact）**
> 我們不只是做一款 Hackathon 作品，而是為 ASD 孩子打造一個隨時可以回去的數位安全巢。謝謝。
